# Varde Android app

Reserved for the native Android client. No Android code or build scaffolding exists yet.

The app will read alerts from the [backend](../backend/), render validated rich views with app-owned styling, and recover missed changes through authenticated sync. These client features are not implemented by the backend's first slice.

See the [project overview](../README.md) and [backend architecture](../docs/architecture/backend.md) for scope and agreed contracts.
